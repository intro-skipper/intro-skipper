The Timestamps section displays all currently detected segments, organized by library, show, season, and segment type.

Selecting a show or movie opens a table of timestamps separated by season.

Click the **Manage** button (gear icon, top right) to open the season management menu, where you can:

- Set a specific analysis method for each segment type in the season
- **Scan Season** — Run a targeted analysis on the selected season without scanning the entire library
- **Erase Season Timestamps** — Remove all detected segments for the selected season

For instructions on manually editing individual timestamps, see [Edit Timestamps & Fingerprints](https://github.com/intro-skipper/intro-skipper/wiki/Edit-Timestamps-&-Fingerprints).
