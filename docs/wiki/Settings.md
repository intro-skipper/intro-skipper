The plugin settings are organized into the following sections.

## [General](https://github.com/intro-skipper/intro-skipper/wiki/Settings-%E2%80%90-General)

*Core scanning options: what to scan, exclusions, auto-detect, and UI settings*

## [Analysis](https://github.com/intro-skipper/intro-skipper/wiki/Settings-%E2%80%90-Analysis)

*Segment duration limits, analysis percentage, and chromaprint settings*

## [Playback](https://github.com/intro-skipper/intro-skipper/wiki/Settings-%E2%80%90-Playback)

*Fine-tune how segment boundaries are determined: silence detection, keyframe snapping, chapter snapping, and playback offsets*

## [Black Frame Detection](https://github.com/intro-skipper/intro-skipper/wiki/Settings-%E2%80%90-Black-Frame)

*Settings for black frame analysis used to detect credits and recap boundaries*

## [Performance](https://github.com/intro-skipper/intro-skipper/wiki/Settings-%E2%80%90-Performance)

*FFmpeg process configuration, parallelism, caching, and system resource settings*

## [Timestamps](https://github.com/intro-skipper/intro-skipper/wiki/Settings-%E2%80%90-Timestamps)

*View and edit detected segment timestamps per show and season*

## [Anime](https://github.com/intro-skipper/intro-skipper/wiki/Settings-%E2%80%90-Anime)

*Special settings for anime series: first episode handling and post-credits preview generation*

## [Chapter Detection Patterns](https://github.com/intro-skipper/intro-skipper/wiki/Chapter-Detection-Patterns)

*Regular expressions used to identify segment types from chapter names in media files*
